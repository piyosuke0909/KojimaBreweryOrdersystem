# 複数LINEアカウントの企業登録検証

検証日: 2026-10-20（日本時間）

同じ企業の招待QRから、異なるLINEアカウントをそれぞれ注文担当者として登録できます。標準の招待上限は5人で、管理者が招待ごとに変更できます。1つのLINEアカウントを別企業へ変更するには、先に管理者による紐づけ解除が必要です。

## 自動テストの結果

| 確認対象 | 結果・検証方法 |
| --- | --- |
| 異なるアカウントを同じ企業へ追加 | 成功。実Honoの登録APIとSQLiteで別々のLINE IDを保存し、それぞれの署名Cookieから本人と企業を復元 |
| IDトークンとユーザーアクセストークン | 両方式で登録・再ログインを確認。LINE公式APIの応答はテスト内で置換 |
| 同じ人の再登録 | 登録人数・監査・利用者の重複を増やさず、元の利用者情報を維持 |
| 別企業への誤紐づけ | HTTP 409で拒否し、元の企業セッションと相手企業の招待枠を維持 |
| 招待上限 | 上限到達後の新規登録を拒否。既存利用者の再読込は可能。管理者による上限追加後は新規登録可能 |
| 無制限の招待 | 上限を無制限にした招待で6人の登録と個別セッションを確認 |
| 同時登録 | 8人で上限3人を超えない。同じ人の8回同時再試行は1人分。同一LINE IDが2企業へ同時登録しても1企業のみ成功し、失敗側の枠は消費しない |
| 独立したブラウザー | 異なる2利用者が同じ企業へ各自登録し、それぞれの担当者名で完了・注文画面へ進む |
| 同じブラウザーでアカウントを切替 | 前の担当者表示や企業の登録判定を引き継がず、新しい本人として登録完了 |

## 本番・実機で確認できた範囲

本人のLINEでの登録完了報告と本番APIにより、A商店の有効なLINE利用者1人・招待使用1回を確認済みです。今回使った招待は上限5人・使用1人で、残り4人です。

別の実LINEアカウントはユーザーが現時点で用意できないため、2人目の実機登録は未確認です。上記の自動テストを、実際の2つ目のLINEアカウントでの確認成功とは扱いません。

実機確認の際は別のLINEアカウントで同じ招待QRを開き、担当者名を入力して登録します。管理画面 → 取引先管理 → A商店 → LINE利用者で、各担当者が別々に登録されたことを確認してください。招待の使用人数も2人になり、最初の担当者の注文画面が引き続き利用できれば確認完了です。
