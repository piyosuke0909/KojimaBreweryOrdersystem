# 請求書の表示内容の編集・納品書の発行履歴

更新日: 2026-10-23（日本時間）

## 会社ごとの未読通知

取引先一覧の会社名の横に、その管理者の赤い未読件数を表示します。会社詳細ではLINEと注文の未読件数を分けて確認できます。赤いリンクを押すと、該当する未読通知を1件既読にして注文またはLINE会話へ移動します。会社の一覧や基本情報を開くだけでは、一括既読にしません。

件数は表示中の会社について25秒ごと、画面に戻ったとき、既読処理の後に再取得します。既読状態は他の管理者と分けて保存します。

## 請求書のプレビューから編集

請求管理から請求書の最新プレビューを開き、「表示内容を編集」を選びます。宛名・住所・帳票タイトル・支払期日・備考・発行元や振込先の表示内容を変更し、プレビューで確認してから新しい版として保存します。

**数量・単価・送料・税率・税額・合計は、元の注文と請求計算から確定した値を使用し、この編集では直接変更しません。** 金額を直す場合は、請求取消・元注文の修正・請求再発行という既存の手順を使ってください。発送状態や入金状態、請求ロック等によって操作が制限される場合があります。

表示内容の修正では注文や請求金額、請求ロックを変更せず、元の発行版を残して新しい版を保存します。別の管理者が先に更新した場合は、その内容を上書きせず再読込を促します。過去の発行履歴のプレビューは閲覧用です。会社情報・振込先のマスタを後から変更しても、過去の版へ適用しません。

## 納品書のプレビューと発行

請求詳細の「請求書の操作」の下にある「納品書の操作」で、対象の注文を選びます。プレビューで内容を確認し、発行の確認操作を行うと、注文・発行元情報・帳票設定・発行日時を固定した履歴を保存します。

プレビューを開くことやPDFをダウンロードすることだけでは、新しい発行履歴を増やしません。同じ発行操作の通信再試行でも同じ履歴を返します。納品書の発行は、注文の金額、注文状態、請求金額、請求ロックを変更しません。

請求書の対象外の注文を別企業の請求へ紐づけることや、古い注文・請求の版で発行することは拒否します。取消済み等、現在の状態によって発行できない場合は案内を表示します。

## 発行履歴から再プレビュー

請求詳細で「請求書の発行履歴」と「納品書の発行履歴」を確認できます。履歴のプレビューは保存した内容を使い、後日注文やマスタが変わっても当時の表示を再現します。請求書の表示内容を修正した版と、請求の取消・再発行も区別して記録します。

導入前の納品書は発行時点の会社情報等を固定していなかったため、当時の内容を推測して履歴として追加しません。納品書の保存履歴は、この機能で明示的に発行した分から蓄積します。既存の請求書の発行履歴は維持します。

## 導入と確認

追加マイグレーション `0009_billing_documents.sql` が必要です。発行・表示修正の保存は監査記録と同じトランザクションで行います。管理者認証、書込時のCSRF対策、版の照合、同一要求の再試行を検証します。

型検査・ビルド、単体300件・統合26件・ブラウザー98件の計424件が成功しました。本番へ反映し、既存データと金額・履歴の保持、未認証APIの拒否、390/768/1366pxでの表示を確認しました。本番の確認のために、実際の請求書や納品書を試験発行していません。詳細は [実装状況](implementation-status.md) に記録しています。
