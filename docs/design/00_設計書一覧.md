## v2.0の主な変更点（v1.3からの改訂内容）

- **技術スタックの刷新（GAS脱却・Cloudflare無料枠構成）**:
  - GAS + Google Sheets + Google Drive 構成を廃止し、**TypeScript + Hono (Cloudflare Workers) + Cloudflare D1 (SQLite / Drizzle ORM) + React (Vite)** 構成へ全面移行。
  - 課金要因となる外部オブジェクトストレージ（Cloudflare R2 / Google Drive）を使用せず、発行済み帳票データは **Cloudflare D1 にスナップショットJSONとして保存** し、画面上でいつでも **帳票プレビュー表示・PDFダウンロード・印刷** ができる構成を採用。
- **企業単位で複数人が読み取れるQRコード招待方式**:
  - 企業ID（取引先ID）に紐づく招待QRコード（および招待URL）を管理画面で発行し、同一企業の複数スタッフ（店長・発注担当者など）が同じQRコードを読み取って登録できる仕様に変更（登録可能人数上限 `max_uses`・有効期限 `expires_at`・即時無効化に対応）。
  - 初回登録画面（`L-01`）で「担当者名」を入力する仕様を追加。
  - `QRコード読み取り → LINEログイン → 公式アカウント友だち追加 → ウェルカム通知 → リッチメニュー → 注文` の一連の導線を確立。
- **企業別定価（取引先別販売単価）と注文単価維持のシンプル化**:
  - 取引先×商品ごとに販売単価（税抜統一）を設定可能とし、未設定時は商品マスタの標準卸価格を適用。
  - 複雑だった `注文価格ロット` テーブルを廃止し、**同一注文内の編集では初回注文時の単価をそのまま維持**する仕様に統一（注文編集で新規追加された別商品のみ追加時点の単価を適用）。
- **帳票プレビュー画面（`A-24`）の追加**:
  - 納品書、御請求書（適格請求書登録番号・振込先銀行口座入り）、取引先配布用QRコード招待案内状の3帳票について、A4レイアウトの画面プレビューとワンクリックPDFダウンロード・印刷機能を追加。
- **設計書間の不整合解消・セキュリティ強化**:
  - 管理ポータルに管理者ログイン認証（`A-00`）を追加。
  - 注文ステータスを「受付済 / 確認済 / 配送準備中 / 発送済 / 完了 / キャンセル済」の6種に全設計書で統一。
  - 商品マスタに商品紹介用カラム（こだわり・味わい・おすすめの飲み方）を追加。
  - 会社情報マスタに請求書振込先用の銀行口座情報カラムを追加。
  - 新規注文時の最短到着希望日リードタイム設定を追加。
