# 管理者ポータル 画面設計書

作成日: 2026-10-19  
版: 2.0（TypeScript + Hono + Cloudflare D1 対応版）

## 1. UI基本方針

- PCおよびタブレット（横画面）を主対象とする。
- **高齢者やITに不慣れなスタッフでも迷わず操作できるUI**とする：
  - 文字サイズを大きく（本文16px以上、見出し20px以上）、コントラストをはっきりさせる。
  - 左サイドバー固定メニュー＋右メイン領域のシンプルな2カラム構成。
  - 専門用語や内部IDではなく、「会社名」「商品名」「日本語ステータス」を優先表示する。
  - データの物理削除は行わず、「無効化」「販売停止」「キャンセル」による安全な状態管理を基本とする。
  - 単価変更・注文変更・請求書発行・QR無効化などの重要操作は必ず確認ダイアログを挟み、自動で監査ログに記録する。
- **帳票プレビュー＆PDFダウンロード機能（Cloudflare R2不使用）**:
  - 納品書、御請求書、QR招待案内状はすべて管理画面上でA4プレビュー表示（`A-24`）でき、ワンクリックでPDFダウンロードまたはプリンタ印刷が可能。

### 4.5 A-11 商品追加・編集（商品紹介4枠対応）

- **基本情報**: 商品名、商品区分、容量(ml)、単位、標準卸価格（税抜）、1本重量(kg)、商品画像、販売状態（販売中/販売停止/注文不可）、業者限定フラグ
- **商品紹介ページ（`L-16`）用の4枠テキスト入力**:
  1. 商品説明（`description`）
  2. こだわり（`commitment`）
  3. 味わい（`taste`）
  4. おすすめの飲み方（`recommended_way`）

### 4.6 A-17 請求詳細・発行 ＆ A-18 請求書発行履歴

- **A-17 請求詳細・発行**:
  - 取引先と対象期間（締日基準）を選択すると、期間内の対象注文（発送済・完了、または到着日基準）を自動抽出する。
  - 税計算単位が「請求単位」の場合、対象注文の税抜合計（商品小計＋課税配送料）に対して消費税率と端数処理を適用し、正式な消費税額と税込請求合計を算出する。
  - `[請求書を発行してロックする]` を押すと、その時点の帳票全データ（宛先・明細・金額・小島醸造の会社情報・銀行口座・インボイス登録番号）を `invoice_histories.snapshot_json` に保存し、対象注文すべてを請求ロック（`is_invoice_locked = 1`）にした上で、`A-24 帳票プレビュー` を開く。
- **A-18 請求書発行履歴**:
  - 過去の版（v1, v2...）の一覧を表示し、どの版でも `[📄 プレビュー・PDFダウンロード]` から当時と同一内容の請求書を再出力できる。
  - 注文内容の修正が必要な場合は `[請求取消]` ボタンから理由を入力して取り消し、対象注文の請求ロックを解除できる。

### 4.7 A-21 会社情報・振込口座設定

請求書・納品書に印字する小島醸造の情報を管理者がいつでも変更できる。

- **会社基本情報**: 会社名、帳票表示名、郵便番号、住所、TEL、FAX、Mail、担当者名、適格請求書発行事業者登録番号（`T`+13桁）
- **請求書記載用 振込先銀行口座情報**:
  - 銀行名（例：〇〇銀行）
  - 支店名（例：犬山支店）
  - 預金種別（普通 / 当座）
  - 口座番号（7桁、6桁の場合は先頭0埋め）
  - 口座名義（例：コジマジョウゾウ（カ）

#### 対応帳票（3種類）
1. **納品書**: 注文詳細画面（`A-03`）から起動。
2. **御請求書**: 請求詳細・発行履歴画面（`A-17` / `A-18`）から起動。
3. **LINE注文サービス QRコード招待案内状**: 招待管理画面（`A-08`）から起動。取引先名、QRコード画像、登録手順（①QR読み取り→②担当者名入力→③リッチメニューから注文）、有効期限をA4 1枚にまとめた案内状をプレビュー＆PDF保存・印刷できる。
