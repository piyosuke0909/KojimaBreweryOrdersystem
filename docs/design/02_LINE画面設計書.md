# LINE / LIFF 画面設計書

作成日: 2026-10-19  
版: 2.0（TypeScript + Hono + Cloudflare D1 対応版）

## 1. 基本デザイン方針

- スマートフォン縦画面（LIFFブラウザ）を基準とする。
- 背景は清潔感のある白（`#FFFFFF` / `#F8FAFC`）を基調とする。
- ブランドカラーの紺（`#1E293B` / `#0F172A`）・金（`#B45309` / `#D97706`）をアクセントとして使用する。
- 大きな装飾ヘッダーは使用せず、ファーストビューから商品をすぐに選べるレイアウトとする。
- 商品画像、商品名、**取引先別販売単価（税抜）**、数量操作（`[-]` `[+]`）を最優先で大きく表示する。
- 注文画面下部には固定カートバーを配置し、Bottom Sheet（下からスライドするシート）でカート詳細を展開する。
- 金額表示は右寄せ・等幅フォント、合計金額は太字で強調する。
- 主要アクションボタンは画面幅いっぱいの大きさ（高さ48px以上）を確保し、タップミスを防ぐ。

## 2. LINEリッチメニュー構成

```text
┌───────────────────┬───────────────────┐
│                   │                   │
│      注 文        │     注文履歴      │
│   (/order へ遷移) │  (/orders へ遷移) │
├───────────────────┼───────────────────┤
│                   │                   │
│   お問い合わせ    │     商品紹介      │
│ (/contact へ遷移) │ (/products へ遷移)│
└───────────────────┴───────────────────┘
```

### リッチメニュー遷移先（同一LIFFアプリ内のルーティング）
- **注文** → `/order`（`L-03 注文商品一覧`）
- **注文履歴** → `/orders`（`L-09 注文履歴`）
- **お問い合わせ** → `/contact`（`L-17 お問い合わせ`）
- **商品紹介** → `/products`（`L-15 商品紹介`）

## 4. L-01 招待登録（QRコード読み取り時）

企業単位で発行されたQRコードを読み取り、LINEログイン＆友だち追加が完了した後に表示される。

```text
┌──────────────────────────────────┐
│ 小島醸造 法人注文サービス        │
├──────────────────────────────────┤
│                                  │
│           ○○酒店 様              │
│                                  │
│ このLINEアカウントを             │
│ ○○酒店 の注文担当者として        │
│ 登録します。                     │
│                                  │
│ ご担当者名（必須）               │
│ ┌──────────────────────────────┐ │
│ │ 山田 太郎                    │ │
│ └──────────────────────────────┘ │
│ ※初期値としてLINE表示名が入ります│
│  フルネーム等へ変更してください。│
│                                  │
│ ┌──────────────────────────────┐ │
│ │          登録する            │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

### 入力・検証仕様
- **担当者名（`staff_name`）**: 必須入力（初期値としてLIFFプロフィールから取得した `displayName` を自動セットし、利用者が「山田 太郎」など実名に書き換え可能とする）。
- **すでに同じ企業へ登録済みのLINEアカウントの場合**: `L-01` をスキップし、「すでに○○酒店として登録済みです」とトースト表示して `L-03 注文商品一覧` へ自動遷移する（招待QRの登録人数枠は消費しない）。
- **エラー遷移（`L-18` へ）**:
  - 招待QRコードの有効期限切れ（`expires_at` 超過）
  - 招待QRコードの登録可能人数上限（`used_count >= max_uses`）に到達済み
  - 管理者により無効化済み（`status = 'revoked'`）
  - すでに**別の取引先企業**へ紐付け済みのLINEアカウントである場合

## 6. L-03 注文商品一覧

```text
┌──────────────────────────────────┐
│ 注文                 ○○酒店 様   │
├──────────────────────────────────┤
│ 📍 配送先: ○○酒店 本店    [変更] │
├──────────────────────────────────┤
│ ┌──────┐ 犬山忍冬酒：侍の酒      │
│ │ 画像 │ 新酒・ガラス瓶 / 300ml  │
│ │      │ 深い香りとすっきりした後味│
│ └──────┘ 販売単価 ¥2,100 (税抜)  │
│                  [ - ]  2  [ + ] │
├──────────────────────────────────┤
│ ┌──────┐ 忍冬梅酒：くノ一の酒    │
│ │ 画像 │ 新酒・ガラス瓶 / 500ml  │
│ │      │ 芳醇な梅の香りと上品な甘み│
│ └──────┘ 販売単価 ¥4,100 (税抜)  │
│                  [ - ]  0  [ + ] │
├──────────────────────────────────┤
│ 🛒 1商品 / 2本   小計 ¥4,200     │
│ [         カートを見る         ] │
└──────────────────────────────────┘
```

### 表示・制御ルール
- **販売単価**: ログイン中の `lineUserId` に紐づく `company_id` 専用の取引先別販売単価（未設定時は標準卸価格）を税抜表示する。
- **業者限定商品**: `is_limited = 1` の商品は、当該取引先に取扱可（`is_available = 1`）の単価設定がある場合のみ一覧に表示する。
- **販売停止・価格未設定商品**: 80ml商品など価格未設定または販売停止の商品は「現在注文できません」と表示し、`[+]` ボタンを無効化する。

## 10. L-07 注文確認 ＆ L-08 注文完了

### L-07 注文確認
- 取引先名、配送先、到着希望日、商品明細（単価・数量・小計）、梱包個口、配送料、消費税、税込合計を一覧表示する。
- 画面表示時に一意の `request_id` を生成し、`[注文を確定する]` 押下時はボタンをローディング状態にして二重押下を防止する。

### L-08 注文完了
- 注文番号（例：`O202610190001`）、注文日時、到着希望日を表示する。
- 確定と同時に、小島醸造の通知用Gmailへメール通知を送り、注文者のLINEトーク画面にも「ご注文を受け付けました」とプッシュメッセージを送信する。

## 11. L-09 注文履歴 ＆ L-10 注文詳細

### L-09 注文履歴
- ステータスフィルタ：`[すべて]` `[受付済]` `[確認済]` `[配送準備中]` `[発送済]` `[完了]` `[キャンセル済]`
- 自社（同じ `company_id`）の注文のみ閲覧可能（同じ会社の別担当者が発注した履歴も共有閲覧できるため、重複発注を防止できる）。

### L-10 注文詳細
- 注文番号、注文日時、最終更新日時、注文担当者名、ステータス、配送先、到着希望日、商品明細、梱包・送料、消費税、税込合計、変更・キャンセル期限（到着希望日の3営業日前17:00）を表示する。
- 条件（`受付済` または `確認済` かつ `期限内` かつ `請求ロックなし`）を満たす場合のみ、`[注文内容を編集]` と `[注文をキャンセル]` ボタンを表示する。

## 12. L-11 注文編集 ＆ L-12 編集確認 ＆ L-13 編集完了 ＆ L-14 キャンセル確認

### L-11 注文編集（初回注文時単価の維持）
- 編集画面を開いた時点で10分間の編集ロックを取得する（他者が編集中の場合は閲覧のみ案内）。
- **単価維持ルール**:
  - 既存注文に含まれている商品の数量を増減しても、**初回注文時の単価（`order_items.unit_price`）がそのまま維持**される。
  - `[＋他の商品を追加する]` から新規追加した別商品には、編集時点の取引先別販売単価が適用される。
- 数量または到着希望日を変更すると、梱包個口・送料・消費税・合計金額が自動再計算される。

```text
┌──────────────────────────────────┐
│ 注文内容を編集 (O202610190001)   │
├──────────────────────────────────┤
│ ※注文済み商品の単価はそのまま   │
│  維持されます。                  │
│                                  │
│ 犬山忍冬酒：侍の酒 300ml         │
│ 注文時単価: ¥2,100 (税抜)        │
│ 数量: 10本 →    [ - ] 15 [ + ]   │
│ 小計: ¥31,500                    │
│                                  │
│ [ ＋ 他の商品を追加する ]        │
│                                  │
│ 📅 到着希望日                    │
│ [ 2026/10/26（月）          ＞ ] │
│                                  │
│ [      変更内容を確認する      ] │
└──────────────────────────────────┘
```

### L-12 編集確認 / L-13 編集完了
- `L-12`: 変更前と変更後の数量・到着希望日・合計金額を並べて比較表示し、`[変更を確定する]` で保存（`order_revisions` に履歴保存＆ロック解放）。
- `L-13`: 変更完了メッセージと改訂番号（`rev.2` 等）を表示。

### L-14 キャンセル確認
- 確認モーダルを表示し、`[キャンセルを確定する]` を押すとステータスを `キャンセル済 (cancelled)` に更新し、小島醸造へキャンセル通知メールを送信する（注文データは物理削除しない）。

## 13. L-15 商品紹介一覧 ＆ L-16 商品紹介詳細

### L-15 商品紹介一覧
- 白いカード形式で各銘柄の画像・商品名・容量展開・キャッチコピーを表示し、`[詳しく見る]` で詳細へ遷移。

### L-16 商品紹介詳細（4枠構成）
- 商品画像、商品名、容量、商品区分に加え、以下の**4枠**を見やすく表示する：
  1. **商品説明**（`description`）
  2. **こだわり**（`commitment`）
  3. **味わい**（`taste`）
  4. **おすすめの飲み方**（`recommended_way`）
- ※商品紹介ページでは販売単価は表示せず、下部にある `[この商品を注文画面で見る]` ボタンから `L-03 注文商品一覧` へ遷移させる。

## 14. L-17 お問い合わせ ＆ L-18 エラー / 利用不可

### L-17 お問い合わせ
- 管理画面（`A-22`）で設定された電話番号（`tel:` リンクでワンタップ発信）、メールアドレス（`mailto:` リンク）、受付時間、補足案内文を表示する。

### L-18 エラー / 利用不可画面
状況に応じた分かりやすい日本語メッセージと問い合わせ先を表示する：
- 未登録状態（招待QRコードからの登録が必要）
- 招待QRコードの有効期限切れ / 登録上限人数到達 / 無効化済み
- すでに別企業へ登録済みのLINEアカウント
- 取引先アカウントまたは契約が無効状態
- 配送先が未登録
- 注文編集・キャンセル期限切れ / 配送準備中以降 / 請求書発行済みロック中
