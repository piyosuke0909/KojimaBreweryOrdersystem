# 要件差分・決定事項および本番移行前確認事項

作成日: 2026-10-19  
版: 2.0（TypeScript + Hono + Cloudflare D1 対応版）

## 1. v1.3 から v2.0 へのアーキテクチャ・仕様決定事項まとめ

| 項目 | 旧設計（v1.3） | 新設計（v2.0 確定仕様） | 変更理由・メリット |
|---|---|---|---|
| **バックエンド / API** | Google Apps Script (GAS) | **TypeScript + Hono (Cloudflare Workers)** | GAS特有のレスポンス遅延やデプロイ制約を解消し、高速かつ型安全なAPIを実現するため |
| **データベース** | Google Sheets（スプレッドシート） | **Cloudflare D1 (SQLite) + Drizzle ORM** | 26テーブルの外部キー制約、排他ロック、トランザクション整合性をRDBで確実に担保するため |
| **帳票出力・保存** | Google DriveへPDF保存 | **D1スナップショット保存 + 帳票プレビュー画面(`A-24`) + PDFダウンロード/印刷** | Cloudflare R2等の有料ストレージ課金を避け、無料枠内で過去版（v1, v2...）の帳票プレビューとPDF出力を実現するため |
| **招待QRコード運用** | 1回使い切りトークン | **企業単位で複数人が読み取れるQRコード（上限人数・有効期限・無効化対応）** | 1つの取引先企業の複数スタッフ（店長・発注担当者等）が同じQRコード案内状からスムーズに登録できるようにするため |
| **初回登録時の担当者名** | 入力欄なし（DBカラムのみ存在） | **`L-01 招待登録` 画面で「担当者名」を入力必須化** | LINEのニックネーム表示名だけでは誰からの注文か判別できない問題を防ぐため |
| **注文編集時の単価管理** | `注文価格ロット` テーブルで旧単価分と追加新単価分を分割 | **同一注文内は初回注文時単価を維持（`注文価格ロット` 廃止）** | 1つの注文明細・納品書・請求書内で同一商品が複数行に分裂する複雑性をなくし、シンプルな単価保護を実現するため |
| **管理画面のセキュリティ** | フルオープン | **管理者ログイン認証（`A-00`）を導入** | 取引先情報・契約単価・請求データの保護および監査ログの操作者記録を成立させるため |
| **注文ステータス** | 文書により3種と6種が混在 | **全6種（受付済/確認済/配送準備中/発送済/完了/キャンセル済）に統一** | 画面・業務フロー・DB間の不整合を解消するため |
| **商品マスタ項目** | 商品紹介の「こだわり・味わい・飲み方」がDB未定義 | **`products` テーブルおよび `A-11` に4枠分のカラムを追加** | 商品紹介詳細画面（`L-16`）の表示内容を管理画面から編集可能にするため |
| **振込先銀行口座情報** | 請求書要件にのみ記載（DB未定義） | **`company_info` テーブルおよび `A-21` に銀行口座カラムを追加** | 請求書プレビュー・PDF（`A-24`）に振込先口座を正しく印字・変更可能にするため |

## 2. 本番運用開始前に小島醸造様へ確認・登録いただく事項

以下の項目はすべて**管理画面（`A-09`〜`A-23`）からコード修正なしで変更可能**な設計としているため、開発時は初期テスト値で実装を進め、本番公開前に管理画面から正式値を入力する。

1. **正式な会社情報・インボイス登録番号・振込先銀行口座（`A-21`）**
   - 郵便番号、住所、TEL、FAX、メールアドレス、適格請求書発行事業者登録番号（`T`+13桁）
   - 請求書に記載する銀行名、支店名、預金種別（普通/当座）、口座番号（7桁）、口座名義
2. **正式なお問い合わせ先情報（`A-22`）**
   - LINEの「お問い合わせ」画面に表示する電話番号、メールアドレス、受付時間
3. **商品画像および商品紹介ページの正式文章（`A-11`）**
   - 各銘柄の商品画像、商品説明、こだわり、味わい、おすすめの飲み方
   - 80ml商品の販売開始時期および標準卸価格
4. **梱包箱サイズとヤマト運輸の運賃表（`A-13` / `A-15`）**
   - 実際に現場で使用している段ボール箱の内訳（1800ml用、700ml/500ml/300ml用）の寸法・重量・最大本数
   - 小島醸造様がヤマト運輸と契約されている地域別・サイズ別の契約運賃表
5. **税計算単位・端数処理の最終確認（`A-20`）**
   - 初期設定は「税抜単価」「消費税10%」「請求単位で計算」「端数切り捨て」「配送料は課税」としているが、現行の経理処理と相違がないか確認。
6. **LINE公式アカウント・LINE Developers チャネル情報**
   - LINE Login チャネル（LIFF ID）および Messaging API チャネルのシークレット・アクセストークン設定。
