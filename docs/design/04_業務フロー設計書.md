# 業務フロー設計書

作成日: 2026-10-19  
版: 2.0（TypeScript + Hono + Cloudflare D1 対応版）

## 1. 初回登録・QRコード紐付けフロー（企業単位・複数人対応）

1つの取引先企業に対して発行したQRコードを、その企業の複数スタッフ（店長、発注担当者A・Bなど）が読み取って登録できるフロー。

```mermaid
flowchart TD
    A["管理者が取引先を登録 (A-05)"]
    B["招待QRコード発行 (A-08)<br/>※上限人数(例:5名)・有効期限設定"]
    C["QR招待案内状をプレビュー・PDF保存/印刷 (A-24)<br/>取引先へ配布"]
    D["取引先スタッフがスマホでQR読み取り"]
    E["LINE Login & 公式アカウント友だち追加"]
    F{"招待トークン検証<br/>(期限内 & 上限人数未満?)"}
    G["L-01: 取引先名確認 & 担当者名入力"]
    H["D1へ (LINE userId ↔ 取引先ID) 保存<br/>& QR使用回数 +1"]
    I["LINE Messaging APIでウェルカム通知"]
    J["L-02: 登録完了 → リッチメニューから注文可能"]
    X["L-18: エラー表示<br/>(期限切れ / 上限到達 / 別企業登録済)"]

    A --> B --> C --> D --> E --> F
    F -- "Yes" --> G --> H --> I --> J
    F -- "No" --> X
```

## 2. 通常注文フロー

2回目以降はLINE公式アカウントのリッチメニュー「注文」をタップするだけで、自動的に取引先と企業別販売単価が識別される。

```mermaid
flowchart TD
    A["リッチメニュー『注文』タップ"]
    B["LIFF起動 & ID Token送信"]
    C["Hono API: lineUserIdから取引先ID特定"]
    D["既定の配送先セット (L-04で変更可)"]
    E["商品一覧 & 取引先別販売単価(税抜)取得・表示 (L-03)"]
    F["商品の数量選択 (±ボタン)"]
    G["カート展開 (L-05)"]
    H["自動梱包計算 & ヤマト送料計算"]
    I["到着希望日選択 (L-06: リードタイム×配送ルール×カレンダー)"]
    J["消費税計算 (参考税額または注文単位税額)"]
    K["注文確認画面 (L-07: request_id 発行)"]
    L["Hono API: request_id 冪等性チェック"]
    M["D1 トランザクション保存<br/>(orders / order_items / order_packages / audit_logs)"]
    N["通知送信<br/>(小島醸造へGmail通知 + 顧客へLINE完了通知)"]
    O["注文完了画面 (L-08)"]

    A --> B --> C --> D --> E --> F --> G
    G --> H --> I --> J --> K --> L --> M --> N --> O
```

## 3. 注文編集フロー（初回注文時単価の維持）

確定済み注文の直接編集フロー。**同一注文内の既存商品は初回注文時の単価を維持**し、新規追加した別商品のみ編集時点の取引先別販売単価を適用する。

```mermaid
flowchart TD
    A["注文詳細画面 (L-10 / A-03)"]
    B{"ステータスが<br/>受付済 or 確認済?"}
    C{"到着希望日の<br/>3営業日前17:00以前?"}
    D{"請求ロックなし?<br/>(is_invoice_locked = 0)"}
    E{"編集ロック取得可能?"}
    F["編集画面開始 (L-11 / A-04)<br/>※10分間ロック取得"]
    G["数量変更（初回注文時単価を維持）<br/>※新規別商品追加時のみ現在単価を取得"]
    H["梱包・送料・税額の自動再計算"]
    I["変更内容確認画面 (L-12)"]
    J{"楽観ロック検証<br/>(version一致?)"}
    K["D1 トランザクション保存<br/>(注文更新 + 注文変更履歴 rev保存 + 監査ログ + ロック解放)"]
    L["変更完了画面 (L-13) & メール通知"]
    X["編集不可表示"]
    Y["閲覧のみ (他者が編集中)"]
    Z["競合エラー・再読込案内"]

    A --> B
    B -- "No" --> X
    B -- "Yes" --> C
    C -- "No" --> X
    C -- "Yes" --> D
    D -- "No" --> X
    D -- "Yes" --> E
    E -- "No" --> Y
    E -- "Yes" --> F --> G --> H --> I --> J
    J -- "No" --> Z
    J -- "Yes" --> K --> L
```

## 4. 注文ステータス遷移フロー

```mermaid
stateDiagram-v2
    [*] --> 受付済 : 顧客が注文確定
    受付済 --> 確認済 : 管理者が内容確認
    受付済 --> キャンセル済 : 顧客(期限内) or 管理者がキャンセル
    確認済 --> 配送準備中 : 管理者が梱包・出荷手配開始
    確認済 --> キャンセル済 : 顧客(期限内) or 管理者がキャンセル
    配送準備中 --> 発送済 : 出荷・配達出発
    発送済 --> 完了 : 納品完了
```

- 顧客がLINEから編集・キャンセルできるのは **`受付済` または `確認済`**（かつ到着希望日の3営業日前17:00以前・請求ロックなし）のみ。

## 5. 請求書発行・プレビュー・PDF出力フロー（R2不使用）

```mermaid
flowchart TD
    A["締日到来 (管理画面 A-16 / A-17)"]
    B["対象期間・取引先の対象注文を抽出"]
    C["請求内容・明細の確認"]
    D["請求単位での消費税・端数処理の正式計算"]
    E["D1 トランザクション保存:<br/>1. invoices / invoice_items 作成<br/>2. invoice_histories に帳票全データの snapshot_json 保存<br/>3. 対象注文を請求ロック (is_invoice_locked = 1)<br/>4. 監査ログ記録"]
    F["帳票プレビュー画面 (A-24) を表示"]
    G["管理者が [PDFダウンロード] または [印刷] を実行"]

    A --> B --> C --> D --> E --> F --> G
```

## 6. 請求取消・注文修正・請求書再発行フロー

請求書発行後に対象注文の修正が必要になった場合の業務フロー。

```mermaid
flowchart TD
    A["請求詳細・発行履歴画面 (A-17 / A-18)"]
    B["管理者が取消理由を入力して [請求取消] を実行"]
    C["D1 トランザクション更新:<br/>1. 請求ステータスを取消済へ更新<br/>2. invoice_histories に取消履歴を記録<br/>3. 対象注文の請求ロックを解除 (is_invoice_locked = 0)<br/>4. 監査ログ記録"]
    D["注文編集画面 (A-04) で必要な注文修正を実施"]
    E["請求画面 (A-17) で再集計し、新版 (v2) として請求書を再発行"]
    F["v2 の snapshot_json を保存 & 対象注文を再ロック"]
    G["帳票プレビュー画面 (A-24) から v2 のPDFをダウンロード・印刷"]

    A --> B --> C --> D --> E --> F --> G
```

※過去に取り消した `v1` の請求書も、`invoice_histories` の `snapshot_json` からいつでも当時の内容でプレビュー確認が可能。
