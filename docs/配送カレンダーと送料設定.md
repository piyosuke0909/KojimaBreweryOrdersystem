# 配送カレンダーと送料設定

## 休業日だけを登録する

管理画面の「配送管理」→「配送カレンダー」で日付を押し、「休業日にする」で保存します。通常は土日を含めて休みなしです。休業日を押した場合は「休業日を解除」で通常営業に戻せます。休業のメモは任意です。

通常営業日でも、取引先の配送ルール・毎月の配送可能期間・最短リードタイムにより注文できる日が変わります。顧客のカレンダーには、最短配送日から90日間のうち選べる日を表示します。変更・取消期限の営業日計算も、登録された休業日だけを除外します。

配送管理のカレンダーは、休業日の登録・解除に使います。日付を押した画面の注文登録リンクは削除しました。管理者が注文を作成する場合は「注文管理 → 注文を登録」を使ってください。顧客は注文時に、到着希望日を月間カレンダーから選択できます。

## 梱包・サイズ・運賃の切り替え

「設定」→「配送・梱包機能」で切り替えて保存します。初期状態はすべてONです。

| 設定 | OFFにしたとき |
| --- | --- |
| 梱包の自動計算 | 梱包箱・ヤマトサイズ・ヤマト運賃のタブを隠し、すべての自動計算を停止 |
| ヤマトサイズの自動判定 | サイズ・運賃のタブを隠し、サイズ判定と運賃計算を停止。梱包計算は継続可能 |
| ヤマト運賃の自動計算 | 運賃タブを隠し、自動運賃を使わず固定送料・管理者指定送料を使用 |

運賃計算にはサイズ判定、サイズ判定には梱包計算が必要です。上位機能がOFFの間は関連機能も無効になります。子の設定値は保持され、上位機能を再びONにすると保存済みの設定が適用されます。

## 自動計算しないときの送料

同じ設定画面の「固定送料（税抜・円）」を登録してください。空欄は未設定、`0`は明示した送料無料として扱います。自社便と送料無料の配送ルールは引き続き無料です。

管理者が新規注文する際は「この注文の送料」で固定送料を上書きできます。固定送料も注文別送料もない有料配送の注文は、エラーになり登録できません。顧客が金額を指定してこの制限を回避することはできません。

既存の注文金額・梱包・請求履歴は、設定変更だけでは更新されません。同じ配送先の注文を編集する際も、保存済みの固定・手動送料を保持します。管理者は注文編集の「配送料を手動で設定」を外すことで、現設定による計算に戻せます。

## 今回の画面変更

管理表の通常行は白に統一し、見出しの色と罫線を残しています。配送管理のタブは折り返し、狭い画面の一覧は項目を縦に並べるため、横スクロールせずに読めます。

顧客のキャンセルは、確認画面で確定するだけです。理由の入力は不要ですが、状態・期限・請求済みロック・更新競合の制限は継続します。管理者が行う取消には監査用の理由を残します。
