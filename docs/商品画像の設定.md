# 商品画像の設定

Googleドライブの画像ファイルの共有リンクを、商品画像に設定できます。共有ページのHTMLではなく、画像表示用URLへ変換して読み込みます。保存済みの共有リンクにも適用するため、貼り直しは不要です。

1. Googleドライブで画像ファイルの「共有」を開きます。
2. 「一般的なアクセス」を「リンクを知っている全員」、権限を「閲覧者」にして、リンクをコピーします。
3. 管理画面 → 商品管理 → 編集 → 「商品画像URL / アセットパス」へ貼り付けます。
4. 「画像を確認」を押し、プレビューが表示されたら「保存する」を押します。
5. 開いたままのLINE注文画面は、一度閉じて開き直します。

フォルダではなく、個別の画像ファイルのリンクを使用してください。一般のHTTPS画像URLやサイト内の画像パスも使用できます。

## 対応するDriveリンク

- `https://drive.google.com/file/d/ファイルID/view`
- `https://drive.google.com/open?id=ファイルID`
- `https://drive.google.com/uc?id=ファイルID&export=view`
- `https://drive.google.com/thumbnail?id=ファイルID`

`resourcekey` が含まれる共有リンクでは、その値も画像表示用URLへ引き継ぎます。画像URLを変更した場合は以前の読み込み失敗状態を引き継がず、新しい画像を表示します。

## プレビューで表示できない場合

共有が「制限付き」になっていないか、ファイルが削除されていないか、フォルダのリンクを使っていないかを確認してください。管理画面には確認に必要な説明を表示します。プレビューの実行だけでは商品情報を保存しません。

管理者のDrive画像プレビューは、認証済み管理者専用のAPIを使います。Googleの既知の画像配信先だけを取得し、取得結果を8MiB・10秒に制限します。HTMLやSVG、画像と一致しないデータは表示しません。Googleへの認証情報の転送や、Driveの共有設定の変更は行いません。
