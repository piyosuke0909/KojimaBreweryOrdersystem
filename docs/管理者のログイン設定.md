# 管理者のログイン設定

更新日: 2026-10-23（日本時間）

管理画面の「設定」→「ログイン設定」で、ログイン中の管理者自身のユーザー名とパスワードを変更できます。会社情報や管理者の表示名を変更する画面とは別です。

1. ログインユーザー名を入力します。半角英数字と `. _ @ + -` を使い、3〜100文字で設定します。
2. 本人確認のため、現在のパスワードを入力します。
3. パスワードも変更するときは、12〜200文字の新しいパスワードを2回入力します。ユーザー名だけを変える場合は、新しいパスワードの欄を空欄にします。
4. 変更内容を確認して保存します。

パスワードは保存後に再表示しません。現在のパスワードが違う場合、確認用の入力が一致しない場合、他の管理者が同じユーザー名を使用している場合は変更できません。他の管理者の権限やログイン情報を、この画面から変更することもできません。

変更後は操作中のブラウザーのログインを更新し、同じ管理者の古いログイン状態を無効にします。他の端末では新しいユーザー名・パスワードでログインしてください。別の管理者やLINE注文者のログイン、LINE設定、QRコードの鍵は変更しません。

新しいパスワードをチャットへ送る必要はありません。設定画面へ直接入力してください。秘密の値やパスワードのハッシュはAPIの応答・監査記録へ出しません。開発用のデモログインにはランダムなパスワードを使用するため、デモボタンからのログインをパスワード変更の本人確認として利用することはできません。

導入には `0010_admin_credentials.sql` が必要です。既存の管理者には初期世代0を追加するだけで、ログイン情報を自動変更しません。単体16件とブラウザー9件で、現在のパスワードの確認、認証・CSRF・競合・旧セッション失効・秘密情報を含めない応答と画面操作を検証しました。本番での画面表示と既存ログインも確認しています。本番の検証のために、既存管理者のパスワードを変更していません。
